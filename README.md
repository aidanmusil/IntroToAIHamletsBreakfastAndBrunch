# Hamlet's Breakfast and Brunch

Three-page fictional restaurant website for a course project.

## Run
Open `index.html` in a browser, or use VS Code Live Server. Use the navigation links to access Menu and Order.

## Files
- `index.html`: home/about, FAQ
- `menu.html`: menu and filters
- `order.html`: cart and demo checkout
- `style.css`: shared responsive design and dark mode
- `script.js`: menu filtering, cart state, theme and checkout validation
- `images/`: AI-generated image crops
- `AI_PROMPT_LOG.md`: prompt history
- `REFLECTION_TEMPLATE.md`: student-authored reflection worksheet

## Important
All restaurant details and prices are fictional. Checkout is a front-end demonstration, not a real purchase. The cart and theme are saved using browser localStorage. Images were cropped from an AI-generated restaurant design concept.
