# AI Workflow and Reflection — Hamlet's Breakfast and Brunch

## How I used AI
I used AI to help generate an initial structure for a three-page restaurant website, a shared CSS stylesheet, JavaScript interactions, and two images. I documented my requests in AI_PROMPT_LOG.md.

## What I changed and why
The only changes I made were some file name changes that I felt made more sense. Other than that, the AI made everything else

## Problems I found and fixed
There was an issue where the cart wouldn't save what was added between the pages, so I asked Chat GPT to fix said error.

## What I learned
I learned that the job market for web developers is most likely gone.

## Ownership of final work
I only gave Chat GPT 3 prompts. The first prompt was telling the AI what I wanted to have included on the website, including the rubric to make sure everything was met. The second prompt double checked some assignment details, as well as having it test the site to see if it works. The third and final prompt was about an issue I found with the cart, which can be found under "Problems I found and fixed"
